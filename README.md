?: Graceful degradation and service workers are related in the way that both deal with enhancing user experiences based on their version of browser. What I mean by that is, since graceful degradation deals with building apps starting with the most modern version of technology while also addressing some support for older versions, then users with older browsers will be unaffected by the modern enhancements of the graceful degradation while still having a functional application. The same is with service workers because when developers write code to "Check if 'serviceWorker' is supported in the current browser" like in B1, and it proves to be unsupported, then that entire code chunk will be skipped over. This allows the app to still function for users, but there will just be a lack of offline support that will cache anything new. This kind of check/verification with implementing service workers allow for the site to just fallback onto normal site requests when its unsupported, which follows the "degrades" gracefully principle in the sense that the site is still fully functional without that "modern" addition.
